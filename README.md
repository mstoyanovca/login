## Login

Java 26/Spring Boot 4/Bootstrap 5/Angular 21 single page application, created to keep up with the latest in Spring Boot and Angular.

### Commands

- git clone from GitHub
- npm install
- ng test
- npm start
- open at http://localhost:4200/
- ng serve --open
- npx kill-port 4200

### Frontend Features

- template forms, validation, custom directive
- router
- auth guard
- JWT interceptor

### Backend Features

- Spring Data
- Spring Security
- REST controllers
- JWT
